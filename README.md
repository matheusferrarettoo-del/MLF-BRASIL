# Landing Page — MLF BRASIL

Landing page estática e independente para apresentar a plataforma MLF BRASIL.

## Conteúdo

- `index.html` — página única, responsiva e informativa.
- `assets/logo-mlf-brasil.png` — logotipo oficial MLF BRASIL enviado pelo proprietário, preparado para fundo escuro e utilizado no cabeçalho e rodapé.
- `assets/favicon.png` — ícone da página baseado no símbolo MLF.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (público ou privado, conforme seu plano e necessidade).
2. Envie o conteúdo desta pasta para a raiz do repositório. O arquivo `index.html` precisa ficar na raiz.
3. Abra **Settings → Pages** no repositório.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub Pages publicar e acesse a URL exibida na própria página de configurações.

## Observações

- Não há backend, banco de dados, login, API, formulário ou coleta de dados.
- A página não se conecta à Shopee, ao Mercado Livre ou à extensão MLF BRASIL.
- A navegação apenas leva às seções informativas da própria página.
- A fonte Sora é carregada do Google Fonts; se o visitante estiver offline, será utilizada uma fonte substituta do sistema.
- Para usar domínio próprio, configure-o depois em **Settings → Pages → Custom domain** e siga as instruções do GitHub.
